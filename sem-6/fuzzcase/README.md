# fuzzcase: номер порта

`ParsePort(s string) (uint16, error)` разбирает номер порта. Разрешены
непустые строки только из ASCII-цифр `0`–`9`; начальные нули допустимы.
Число должно лежать в диапазоне 1–65535. Примеры: `"80"` и `"00080"`
дают `80, nil`, `"0"` и `"65536"` дают `0, ErrPort`. Знаки, пробелы,
Unicode-цифры и произвольный текст недопустимы. Любая ошибка даёт `0, ErrPort`.
Текст ошибки не является частью контракта.

`strconv.Atoi` переводит строку в `int` и возвращает ошибку преобразования.
В `port.go` есть дефект. Исходные тесты его не замечают. Допишите фаззер
`FuzzParsePort` в `fuzz_test.go`, найдите вход, сохраните проверку и исправьте
парсер. Подмена своего фаззера вызовом готового парсера не нужна.

`testing.F` — объект настройки fuzz-теста. `f.Add(s)` добавляет начальный
вход, а `f.Fuzz(func(t *testing.T, s string) { ... })` задаёт проверку для
каждого входа. Go изменяет начальные строки и сохраняет входы, на которых
проверка упала. Фаззер должен проверять контракт, а не требовать, чтобы
произвольная строка была допустимой.

Начните с `"80"`, `"65535"`, `"0"`, пустой строки и недопустимого текста.
Свойство для успешного разбора: исходная строка непустая и состоит только
из ASCII-цифр, а номер лежит в разрешённом диапазоне. Можно дополнительно
проверить разбор канонической записи номера через `strconv.FormatUint`.
Проверку ошибки рассматривайте отдельно от успешного результата.

```shell
go test ./fuzzcase
go test -run '^$' -fuzz '^FuzzParsePort$' -fuzztime=5s ./fuzzcase
```

После падения Go напечатает путь `testdata/fuzz/FuzzParsePort/...` и команду
повторения. Сохраните этот файл, добавьте обычный `TestParsePortRegression`
с найденной строкой и ожидаемым результатом. После исправления обычный
`go test ./fuzzcase` должен проходить и выполнять сохранённый corpus.
Короткий зелёный fuzz-прогон сам по себе не доказывает отсутствие ошибок.

Происхождение: новый короткий parser, без разбора IP-диапазонов и без
лекционного Reverse. Мост к домашнему `iprange`: выбор fuzz-свойства,
минимальный воспроизводимый вход, corpus и обычный regression test.
