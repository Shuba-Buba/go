# linkstore

Сделайте сервис коротких ссылок в памяти:

```go
func New() http.Handler
```

Каждый вызов `New` создаёт независимое хранилище. Обработчик должен безопасно
работать с несколькими запросами одновременно.

## Создание ссылки

`POST /links` принимает `Content-Type: application/json` (параметры вроде
`charset=utf-8` разрешены) и один JSON-объект с полем `url`:

```json
{"url":"https://example.org/docs?q=go#http"}
```

- Неверный или отсутствующий `Content-Type` → `415 Unsupported Media Type`.
- Тело длиннее **1024 байт** → `413 Content Too Large`, даже если длина заранее
  неизвестна. Лимит включает пробелы и проверяется до разбора JSON.
- Пустое или повреждённое тело, лишние поля, второй JSON после объекта,
  отсутствующий или пустой `url` → `400 Bad Request`. Пробелы после объекта
  разрешены.
- Разрешён абсолютный URL со схемой `http` или `https` и непустым именем
  хоста, без имени пользователя и пароля. Недопустимый URL → `400 Bad Request`.

Для нового адреса верните `201 Created`, заголовок `Location: /l/<id>`,
`Content-Type: application/json` и объект `{"id":"<id>"}`. ID непустой,
состоит из букв латиницы, цифр, `-` и `_`. Формат и порядок ID свободные.

Повторный POST с **точно такой же строкой URL** получает `200 OK` и те же
ID и `Location`. Даже при нескольких одновременных POST для одного адреса
ровно один получает `201`. Разным строкам URL соответствуют разные ID.

## Переход по ссылке

`GET /l/{id}` и `HEAD /l/{id}` возвращают `302 Found` с исходным адресом
в `Location`. По этому адресу ходит клиент; сервер только отдаёт заголовок.
Неизвестный ID или путь → `404 Not Found`. Неподдерживаемый метод для
существующего маршрута → `405 Method Not Allowed` с `Allow`. Формат тел
ответов с ошибками свободный.

Подсказка: `ServeMux` понимает шаблоны с методом и переменной в пути;
посмотрите `Request.PathValue`, `http.MaxBytesReader` и
`json.Decoder.DisallowUnknownFields`. Проверка «адрес уже есть?» и выдача
нового ID должны быть одной атомарной операцией.
