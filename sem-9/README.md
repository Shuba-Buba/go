# Семинар 9: HTTP в Go

Сегодня собираем части сервиса коротких ссылок. Клиент создаёт ссылку,
браузер получает перенаправление, сервер записывает результат в журнал,
а отдельная программа проверяет список адресов.

1. [linkstore](linkstore/README.md): реализуйте HTTP API, которое валидирует
   JSON, выдаёт короткие ссылки и переживает одновременные запросы.
2. [accesslog](accesslog/README.md): напишите middleware, которое передаёт
   ID запроса и записывает фактический статус и число отправленных байтов.
3. [linkcheck](linkcheck/README.md): дополнительная задача. Проверьте
   адреса параллельно с лимитом, сохранив порядок и поддержав отмену.

Нужен Go 1.27.0 или совместимый более новый. Внешних зависимостей нет.
Задачи независимы; команды запускайте из `sem-9`.

```shell
go test -run '^$' -timeout=1m ./...
go test -count=1 -race -timeout=1m ./linkstore
go test -count=1 -race -timeout=1m ./accesslog
go test -count=1 -race -timeout=1m ./linkcheck
```

Первая команда проверяет, что шаблоны компилируются. Тесты поведения
изначально падают. Дописывайте реализации в файлах без суффикса `_test.go`.
Тесты работают локально, без подключения к интернету.
