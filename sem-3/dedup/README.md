# dedup

Реализуйте функцию:

```go
func Deduplicate(input []string) []string
```

Функция удаляет повторные строки и сохраняет порядок их первых появлений.

```text
["go", "map", "go", "slice", "map"] -> ["go", "map", "slice"]
```

Входной slice менять нельзя. Для хранения уже встреченных строк используйте
множество на `map[string]struct{}`. Для `nil` нужно вернуть `nil`; для
не-`nil` пустого slice — не-`nil` пустой результат.

Не стройте ответ обходом map: порядок обхода map в Go не определён.

## Проверка

```shell
go test ./dedup/...
```
