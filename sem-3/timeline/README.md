# timeline

Нужно построить историю изменения целочисленного значения.

```go
type Change struct {
    Day   int
    Delta int
}

type Snapshot struct {
    Day   int
    Value int
}

func Build(initial int, changes []Change) ([]Snapshot, error)
```

Правила:

- изменения одного дня сначала суммируются;
- дни результата идут по возрастанию;
- день с нулевым суммарным изменением в результат не попадает;
- после каждого дня записывается новое накопленное значение;
- значение не может быть отрицательным: в таком случае нужно вернуть
  `ErrNegativeValue` и `nil` вместо частичного результата;
- отрицательное `initial` также является `ErrNegativeValue`;
- входной slice менять нельзя;
- если эффективных изменений нет, верните не-`nil` пустой slice.

Например, для `initial == 2` и изменений `{Day: 3, Delta: -1}`,
`{Day: 1, Delta: 4}`, `{Day: 3, Delta: 2}` результат равен
`[{Day: 1, Value: 6}, {Day: 3, Value: 7}]`.
