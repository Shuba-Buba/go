# countwriter

Напишите обёртку над `io.Writer`, считающую реально принятые им bytes.
`New(dst)` ничего не пишет; `Write(p)` вызывает `dst.Write(p)` ровно один раз.
Счётчик увеличивается на возвращённое `n`, в том числе при одновременной ошибке.
Входной slice нельзя менять или удерживать. Возвращайте ту же ошибку.

Если `n < len(p)`, но writer не вернул ошибку, верните `io.ErrShortWrite`.
Считайте, что `0 <= n <= len(p)`; `dst` ненулевой. Не закрывайте поток.
`BytesWritten()` возвращает накопленное число bytes как `int64`.

```shell
go test ./countwriter/...
```
