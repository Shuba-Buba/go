# gauge

Счётчик показывает уровень в баке. Zero value готов к работе.
Реализуйте `Add(delta int) error`, `Value() int`, `String() string`.

- `Add` изменяет текущий уровень. При отрицательном результате возвращает
  `ErrNegative` и оставляет старое значение. Переполнение int не проверяем.
- `Value` читает уровень, `String` возвращает `level=N`, например `level=7`.
- Через `*Gauge` можно менять состояние. Значение `Gauge` должно реализовать
  `fmt.Stringer` и при копировании получать независимый текущий уровень.
- Nil receiver не поддерживается.

```shell
go test ./gauge/...
```
