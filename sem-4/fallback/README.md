# fallback

Реализуйте `Lookup(primary, backup Source, key string) (string, error)`.
Сначала запросите primary. При успехе верните ответ. Только если ошибка
содержит `ErrMissing` в цепочке, сделайте один запрос к backup с тем же ключом.
Другие ошибки primary сразу завершат операцию.

Оборачивайте ошибки контекстом `primary` или `backup`, сохраняя причину для
`errors.Is` и `errors.As`. При ошибке полезный результат — пустая строка.
Успешная пустая строка тоже является ответом и не требует backup.
Источники ненулевые; циклов повторных попыток и сети нет.

```shell
go test ./fallback/...
```
