# readclose

Реализуйте `Load(open func() (io.ReadCloser, error)) ([]byte, error)`.
Функция получает ресурс во владение, читает его целиком через `io.ReadAll`
и гарантированно закрывает ровно один раз после успешного открытия.

- При ошибке открытия не читайте и не закрывайте ресурс.
- При ошибке чтения верните `(nil, error)`, сохранив причину через `%w`.
- Если чтение удалось, но Close вернул ошибку, также верните `(nil, error)`.
- Если чтение и Close оба неудачны, сохраните ошибку чтения.
- На успехе верните прочитанные bytes и nil. Контекст ошибки должен
  содержать этап `open`, `read` или `close`.
- `open` ненулевая; при успехе она возвращает ненулевой ресурс.

Подсказка: именованные результаты доступны в отложенной функции.

```shell
go test ./readclose/...
```
