# oncecache

Сделайте кэш с ленивой инициализацией на `sync.Once`:

```go
type Cache interface {
    Get(key string) (any, bool)
}
func New(load func(string) any) Cache
```

- Первый доступ к каждому ключу вызывает `load(key)` и запоминает результат.
- Конкурентные первые обращения к одному ключу не дублируют вычисление:
  нужен отдельный `Once` на ключ. Все вызывающие ждут окончания загрузки.
- Последующие `Get` возвращают сохранённое значение без нового `load`.
- Разные ключи могут загружаться независимо: зависший `load("a")` не должен
  удерживать общий mutex и мешать `Get("b")`.
- Второй результат означает успешную загрузку и всегда равен `true`, в том
  числе при первом вызове и когда `load` вернула `nil`. Это не признак того,
  что значение уже находилось в кэше до вызова.
- Разные экземпляры кэша независимы. Методов `Set` и `Delete` нет.

Гарантии вызывающего кода: `load` не равна `nil`, завершается без panic,
не вызывает методы этого же кэша и безопасна для параллельных вызовов
с разными ключами. Полученное значение больше не изменяется либо его
изменения синхронизирует сам пользователь. Обработка panic и повторные
попытки загрузки в это упражнение не входят.

Подсказка: общий mutex защищает таблицу записей. Саму загрузку выполняйте
после освобождения этого mutex. Возврат из `Once.Do` уже означает, что
инициализация закончена и её результат виден вызывающему.
