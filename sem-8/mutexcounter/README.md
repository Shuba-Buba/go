# mutexcounter

Реализуйте потокобезопасный счётчик:

```go
type Counter interface {
    Inc()
    Add(delta int)
    Load() int
}
func New() Counter
```

- Новый счётчик равен нулю; разные экземпляры независимы.
- `Inc` увеличивает значение на 1, `Add` прибавляет положительное,
  нулевое или отрицательное значение.
- Все методы могут вызываться одновременно. Чтение тоже защищает тот же
  mutex: ожидание конца писателей в одном тесте не делает `Load` безопасным.
- Используйте `sync.Mutex`; переполнение `int` не проверяется.

После тестов запустите готовый benchmark, который вызывает `Add` параллельно:

```shell
go test -run '^$' -bench=. -benchmem ./mutexcounter
```

`b.RunParallel` раздаёт работу нескольким горутинам; `pb.Next()` сообщает,
нужно ли выполнить ещё одну итерацию. Сравните время и число allocations.
Не меняйте правильность ради результата benchmark; избегайте лишней работы
в критической секции.
