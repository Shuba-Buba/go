# generate

Реализуйте функцию `Generate(n int) <-chan int` — первое звено pipeline из лекции.

Горутина отправляет на канал числа `0, 1, …, n-1` и закрывает его.
Для `n <= 0` канал закрывается сразу, значения не отправляются.

Возвращаемый канал только для чтения снаружи пакета не обязателен,
но отправлять в него после закрытия нельзя.

```shell
go test ./generate/...
```
