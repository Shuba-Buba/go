# merge

Реализуйте `Merge(chs ...<-chan int) <-chan int` — fan-in для pipeline.

Функция читает из всех входных каналов и пересылает значения в общий
выходной канал. Когда **все** входы закрыты и опустошены, выходной канал
нужно закрыть.

- Порядок значений на выходе не определён — это нормально для fan-in.
- Для пустого списка каналов верните сразу закрытый канал без значений.
- Закрытый пустой вход не блокирует завершение `Merge`.
- Не закрывайте входные каналы — ими владеют вызывающие.

Подсказка: запустите по горутине на каждый вход и дождитесь их через
`sync.WaitGroup` или `select`.

```shell
go test ./merge/...
```
