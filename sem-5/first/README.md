# first

Реализуйте `First(chs ...<-chan int) (int, bool)` — mirrored query из лекции.

Функция ждёт значение из **первого** канала, который его отдаст. Как только
одно значение получено, его нужно вернуть немедленно — остальные каналы
можно не дочитывать.

- Если все каналы закрыты и пусты, верните `ok == false` (значение `0`).
- Для пустого списка каналов — тоже `(0, false)`.
- Входные каналы не закрывайте.

Подсказка: почему в лекции для mirrored query используют
`make(chan T, N)`, а не небуферизованный канал?
