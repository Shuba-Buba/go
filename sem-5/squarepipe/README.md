# squarepipe

Реализуйте `Square(in <-chan int) <-chan int` — стадию pipeline, которая
возводит числа в квадрат.

Читайте из `in` до закрытия, пишите `x * x` в свой канал и закройте его
после завершения чтения. Для закрытого пустого входа верните сразу закрытый
канал без значений.

```shell
go test ./squarepipe/...
```
