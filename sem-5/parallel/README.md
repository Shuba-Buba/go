# parallel

Реализуйте `Parallel(fns ...func() error) error`.

Каждую функцию запускайте в отдельной горутине. Дождитесь завершения всех.
Если хотя бы одна вернула ошибку, `Parallel` возвращает одну из них
(какую — не важно). Если все вернули `nil`, верните `nil`.

Пустой список функций завершается сразу с `nil`.

```shell
go test ./parallel/...
```
