# readinglist

В списке для чтения есть книги с названием и автором. Тесты передают готовый
`*sql.DB` с таблицей:

```sql
CREATE TABLE books (
    id INTEGER PRIMARY KEY,
    title TEXT NOT NULL,
    author TEXT NOT NULL,
    UNIQUE (author, title)
);
```

- `Add` записывает книгу и возвращает ID, который назначила база. Повторная
  вставка книги с тем же автором и названием возвращает ошибку.
- `ByAuthor` возвращает ID и названия книг заданного автора. Порядок задаётся
  названием по возрастанию. Если книг нет, верните пустой список. Допустим `nil`.
- `Remove` удаляет книгу по ID. Если такой книги нет, верните `sql.ErrNoRows`.

Передавайте значения в запросы отдельными аргументами и используйте полученный
`ctx` для обращения к базе. За закрытие `db` отвечает вызывающий код.
Драйвер SQLite поддерживает `sql.Result.LastInsertId` после вставки.

```sh
go test -timeout=1m ./readinglist
```
