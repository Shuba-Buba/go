# Семинар 11. Дженерики в Go

1. [Рекордные показания](readings/README.md). Выберите ограничение для сравнения и сохраните тип слайса.
2. [Каталог по ID](catalog/README.md). Свяжите тип записи и тип ключа через сигнатуру метода.
3. [Листья дерева](treewalk/README.md). Обойдите дерево и передайте значения листьев функции, которую задаёт вызывающий код.

Запускайте тесты из корня модуля по мере решения:

```sh
go test ./readings
go test ./catalog
go test ./treewalk
```

До реализации вызов заглушки завершится паникой с именем функции.
