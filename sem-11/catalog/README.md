# Каталог по ID

Музей прислал список экспонатов. Для поиска по инвентарному номеру нужен
индекс. Другой музей обозначает экспонаты строкой, третий — парой
«зал, номер». Во всех трёх каталогах запись умеет сообщить свой ID.

В `record.go` дан интерфейс `Identified[K]` с методом `ID() K`.
Реализуйте `IndexByID`. Ключом карты становится результат метода, значением —
сама запись. Запись может содержать слайс, поэтому возможность сравнения
требуется только от ключа. Считайте, что каждый возвращённый ID допустим
как ключ карты. Два ID совпадают, если они равны по `==`.

- Разные ID. Верните заполненную карту и `true`.
- Повторный ID. Верните `nil, false`, даже если обе записи выглядят одинаково.
- Пустой или nil-слайс. Верните пустую карту, в которую можно добавлять записи, и `true`.

Например, у двух записей с ID `"a"` и `"b"` будут отдельные ключи. Если
записи пришли с ID `"a", "b", "a"`, построение индекса заканчивается ошибкой
дублирования. Клиент проверяет её по возвращённому `bool`.
