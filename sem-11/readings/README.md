# Рекордные показания

Датчик передаёт измерения в порядке поступления. Напишите `RecordHighs`,
которая возвращает первое измерение и каждое следующее, которое строго
больше всех предыдущих. Для ряда `[-4, -5, -1, -1, -2, 3]` ответ
`[-4, -1, 3]`. Строки сравниваются в лексикографическом порядке:
`["b", "a", "d"]` дают `["b", "d"]`. В вещественных рядах все числа конечны.

Подберите для элемента ограничение, которое разрешает `>` и принимает
встроенные упорядоченные типы и определённые на их основе типы. Вызов
`RecordHighs(values)` должен выводить оба аргумента типа из `values`.
Для `type Series []int16` результат имеет тип `Series`.

Для пустого входа достаточно пустого результата. Функция сохраняет исходные
показания. Если после вызова заменить элемент в результате, входной ряд
должен по-прежнему содержать исходное значение.
