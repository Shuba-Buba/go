# Листья дерева

В дереве каталогов листья обозначают документы. При печати оглавления
понадобятся названия документов, а при подсчёте страниц — числа.
Тип `Tree[T]` уже объявлен в `tree.go`. Данные хранятся в поле `Value`.

Реализуйте `VisitLeaves(root, visit)`. Вызовите переданную функцию
`visit` со значением каждого листа ровно один раз, слева направо.
Лист — узел, у которого оба ребёнка равны `nil`.
Узел с одним ребёнком тоже может быть частью дерева. У пустого дерева
листьев нет, у дерева из одного узла корень сам является листом.

```text
        раздел
       /      \
   текст     приложения
                    \
                   таблица
```

Для этого дерева callback получает `"текст"`, затем `"таблица"`.
Входное дерево конечно и не содержит циклов или общих поддеревьев.
Вызывающий код передаёт функцию и оставляет дерево неизменным во время обхода.
